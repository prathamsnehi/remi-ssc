The face recognition flow is as following:

1. The vector captured becomes an embedding
2. The embedding is normalized and all
3. I match against all of the stored embeddings in the device and run the calculations of distance. If I find something, then I raise a positive (that the person was detected)
4. If i didn't find them, raise the negative state that actions to register that person in the embeddings database (Person class in SwiftData)
